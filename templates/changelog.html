Version & Changelog

Detailed version information and release history for SentinelWP.

SentinelWP v3.6.0 (Stable)

Released: August 2026

Active Version

User Panel & Preferences, Theme Switcher & Navigation Cleanup

  • Unified User Panel & Preferences (/settings): Created a centralized hub for account settings, password management, theme selection, changelog access, and admin user controls.
  • Dark & Light Theme Switcher: Full support for Dark Theme (default) and Light Theme (White) with instant client-side switching and persistent local storage.
  • Streamlined Navigation UI: Cleaned up top-level navigation links by moving Admin User Management and Changelog into the User Panel, preserving clean scanning-focused UI for all users.
  • Column-by-Column Table Headers: Integrated interactive real-time search and filter controls directly into table header rows across Dashboard and Scan History.

SentinelWP v3.5.0

Released: August 2026

Superceded

Non-WP Domain Identification, Auto 30-min Sync & Admin DB Export

  • Non-WordPress Target Identification: Targets without WordPress installed are explicitly categorized and labeled as "Not WordPress" across database records, scan history tables, and exported reports.
  • Automated 30-Minute Threat Intel Sync: Configured background daemon to sync Wordfence & CISA KEV feeds automatically upon app launch and every 30 minutes.
  • Field-by-Field Interactive Filters: Comprehensive multi-attribute filter panel on dashboard and scan history for URL search, Status, Mode, Grade, CMS Type, and Date Range.
  • Admin Unique Scan Database Export: Dedicated single-click action for Administrators to export the complete unique scan history and findings log into a multi-sheet Excel file.
  • Cross-Platform Installation Guides: Comprehensive installation documentation in README.md for macOS, Linux (Debian/Ubuntu & RHEL/Fedora), and Windows (PowerShell/CMD).

SentinelWP v3.4.0

Released: August 2026

Superceded

Enterprise Report Engine & GUI API Key Management

  • Redesigned Zero-Overlap PDF Report Engine: Completely refactored PDF generation using ReportLab Paragraph flowables inside table cells to guarantee zero text truncation or overlap across columns.
  • Dynamic Numbered Page Footers: Implemented custom 2-pass NumberedCanvas to automatically calculate and render total page counts ("Page X of Y"), running headers, and legal disclaimers.
  • Executive Summary & Severity Matrix Cards: Embedded structured executive cards, overall risk gauges, and severity distribution matrices (Critical, High, Medium, Low, Info) in PDF, HTML, and Excel exports.
  • Interactive HTML Security Dashboard Reports: Refactored HTML export with client-side severity tab filtering (All, Critical, High, Medium, Low, Info), instant text search, CISA KEV badges, CVSS 3.1 vectors, and print CSS support.
  • Multi-Sheet Excel Reports: Generated styled Executive Summary and Findings Detail sheets with dark header fills, severity color indicators, sanitized cells, and auto-fitted columns.
  • GUI Configuration for API Keys: Added dedicated API Keys & Source Configuration card directly on the Threat Intelligence dashboard (/vuln-intel) allowing Admins to manage Wordfence and NVD keys via GUI with database persistence.

SentinelWP v3.3.0

Released: August 2026

Superceded

WordPress Vulnerability Intelligence Pipeline

  • Wordfence Intelligence v3 Integration: Automated background feed ingestion for WordPress Core and plugin vulnerabilities with CVSS 3.1 scoring, CWE classification, and affected version ranges.
  • CISA KEV Correlation: Automatically flags vulnerabilities actively exploited in the wild with CISA Known Exploited Vulnerabilities badges and metadata.
  • WordPress.org Popularity Enrichment: Syncs active install counts for plugins to prioritize high-impact vulnerabilities on widely deployed software.
  • Deterministic Version Matcher: Custom version comparator supporting exact, open/closed intervals, unbounded ranges, and prerelease tags (1.9 < 1.10).
  • Threat Intelligence Dashboard & Search: Dedicated UI dashboard (/vuln-intel) with critical vulnerability statistics, stale dataset alerts, manual sync triggers (Admin only), and a paginated, filterable database table (/vuln-intel/list).
  • Zero Network Impact During Scans: All target scans execute version matching purely against the local SQLite database; zero external HTTP requests are performed during scan execution.
  • Enhanced Export Security: Added formula injection protection (=, +, -, @) across CSV and Excel exports, HTML content escaping for external vulnerability descriptions, and SARIF 2.1.0 rule tags.

SentinelWP v3.2.0

Released: August 2026

Superceded

New Scanning Capabilities (Passive & Safe)

  • DNS Security Record Check (SPF & DMARC): Performs passive audits using DNS-over-HTTPS (DoH) via Google DNS APIs to identify the absence or weakness of domain email security policies.
  • Security Policy File (security.txt): Verifies the presence of standard security contact paths adhering to RFC 9116 at /.well-known/security.txt and /security.txt.
  • WordPress Core Vulnerability Lookup (OSV.dev): Extends live CVE matching via OSV.dev to include the detected WordPress Core CMS version.
  • EOL Software Detection: Analyzes server response headers (PHP < 8.2, Apache < 2.4) to flag the exposure of unsupported and unpatched systems.
  • Optimized User Enumeration: Scans the <dc:creator> tags within the main RSS /feed/ to detect exposed usernames.

Reporting & Interactive UI

  • CSV Export: Added a button to the Scan History view to download a complete CSV spreadsheet containing target domains, WordPress versions, detected plugins, and finding counts.
  • Interactive Findings Detail View: Finding rows in the scan detail view are now clickable, expanding an inline drawer that displays the full description, remediation recommendations (formatted as code blocks), external reference links, and raw JSON metadata.

WHOIS Improvements

  • Native WHOIS Client (Port 43): Advanced handling and block-structured parsing for registrar and expiration dates across .com, .it and .eu domains, featuring error tolerance and fallback parsing.
