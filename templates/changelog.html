Version & Changelog

Detailed version information and release history for SentinelWP.

SentinelWP v3.2.0 (Stable)

Released: August 2026

Active Version

New Scanning Capabilities (Passive & Safe)

  • DNS Security Record Check (SPF & DMARC): Performs passive audits using DNS-over-HTTPS (DoH) via Google DNS APIs to identify the absence or weakness of domain email security policies.
  • Security Policy File (security.txt): Verifies the presence of standard security contact paths adhering to RFC 9116 at /.well-known/security.txt and /security.txt.
  • WordPress Core Vulnerability Lookup (OSV.dev): Extends live CVE matching via OSV.dev to include the detected WordPress Core CMS version.
  • EOL Software Detection: Analyzes server response headers (PHP < 8.2, Apache < 2.4) to flag the exposure of unsupported and unpatched systems.
  • Optimized User Enumeration: Scans the <dc:creator> tags within the main RSS /feed/ to detect exposed usernames.

Reporting & Interactive UI

  • CSV Export: Added a button to the Scan History view to download a complete CSV spreadsheet containing target domains, WordPress versions, detected plugins, and finding counts.
  • Interactive Findings Detail View: Finding rows in the scan detail view are now clickable, expanding an inline drawer that displays the full description, remediation recommendations (formatted as code blocks), external reference links, and raw JSON metadata.

WHOIS Improvements

  • Native WHOIS Client (Port 43): Advanced handling and block-structured parsing for registrar and expiration dates across .com, .it and .eu domains, featuring error tolerance and fallback parsing.
