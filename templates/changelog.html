Detailed version information and release history for SentinelWP.

SentinelWP v3.2.0 (Stable)

Released: August 2026

Active Version

🚀 Nuove Funzionalità di Scansione (Passive & Safe)

  • Controllo Record DNS (SPF & DMARC): Esegue controlli passivi utilizzando DNS-over-HTTPS (DoH) tramite le API di Google DNS per identificare l'assenza o la debolezza delle policy di sicurezza email del dominio.
  • Policy File Security.txt (RFC 9116): Verifica la presenza di percorsi standard per le segnalazioni di vulnerabilità da parte dei ricercatori in /.well-known/security.txt e /security.txt.
  • Vulnerabilità Core WordPress (OSV.dev): Estende la ricerca live dei CVE su OSV.dev anche alla versione principale rilevata di WordPress Core.
  • Rilevamento Versioni software EOL (End-Of-Life): Analizza gli header di risposta del server (PHP < 8.2, Apache < 2.4) per evidenziare l'esposizione di versioni non più supportate e prive di patch.
  • Ottimizzazione User Enumeration: Scansiona il tag dc:creator dei feed RSS principali (/feed/) per intercettare username non protetti.

📊 Esportazione e UI Interattiva

  • Export in CSV: Aggiunto pulsante nella scheda di cronologia scansione per scaricare un foglio CSV completo con dominio, versione di WordPress, plugin rilevati e numero di findings.
  • Visualizzazione Findings Espandibile: Le righe dei findings nella pagina di dettaglio scansione sono ora interattive. Un semplice click espande la visualizzazione mostrando descrizione completa, raccomandazioni di correzione (remediation), link a CVE/riferimenti e i metadati tecnici in formato JSON.

🔍 Miglioramenti WHOIS

  • Client WHOIS Nativo (Porta 43): Gestione avanzata per i registrar ed expiry date dei domini .com, .it e .eu, con tolleranza d'errore e parsing a blocchi.
